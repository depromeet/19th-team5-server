# SFU를 Pion으로 직접 구현한다

승인 | YYYY-MM-DD | 관련 RFC: 없음

## 상황

[SFU 구조](0014-voice-use-sfu.md)를 쓰기로 했다. 완성형 SFU 서버를 띄우거나, WebRTC 라이브러리로 직접 만들 수 있다. 면접방 상태와 접속 인증은 Go로 만드는 실시간 서버가 갖는다.

## 결정

Go용 WebRTC 라이브러리 Pion v4로 실시간 서버 안에 SFU를 직접 구현한다.

## 이유

- **LiveKit 같은 완성형 SFU 서버:** LiveKit은 Pion으로 만든 SFU 서버로, 재협상과 재연결 같은 까다로운 부분이 이미 구현돼 있다. 하지만 별도 서버로 돌고 자체 시그널링과 클라이언트 SDK를 쓰므로, 면접방 상태를 실시간 서버와 LiveKit이 나눠 갖게 된다.
- 방이 4명으로 작고 구독 규칙이 '같은 방 전원'으로 단순하다.
- 실시간 서버와 같은 언어의 라이브러리라 한 프로세스 안에 붙일 수 있다.

## 결과

- 얻는 것: 면접방 상태와 시그널링을 실시간 서버 한 곳에서 관리한다.
- 감수하는 것: 재협상, 재연결, 발화 감지를 직접 만들고 테스트해야 한다. 이 구현이 예상보다 어려우면 완성형 SFU 서버를 다시 검토한다.
