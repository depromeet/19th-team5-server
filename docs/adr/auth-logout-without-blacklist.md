# 로그아웃은 리프레시 토큰만 폐기한다

승인 | 2026-11-24 | 관련 RFC: 없음

## 상황

JWT 액세스 토큰은 서명만 맞으면 통과한다. 로그아웃이나 정지 때 아직 만료되지 않은 액세스 토큰을 막으려면 블랙리스트가 필요하다.

## 결정

로그아웃하면 리프레시 토큰만 폐기하고 쿠키를 지운다. 액세스 토큰은 만료(최대 30분)까지 그대로 둔다. 블랙리스트는 두지 않는다.

## 이유

- 블랙리스트를 두면 core와 realtime이 요청마다 저장소를 조회해야 한다. [각 서버가 혼자 검증한다](auth-use-jwt.md)는 이유가 사라진다
- 액세스 토큰을 30분으로 짧게 두면 남는 위험이 30분으로 묶인다. 리프레시 토큰을 폐기했으니 그 뒤로는 새 액세스 토큰을 받을 수 없다

## 결과

- 얻는 것: 검증이 저장소 없이 끝난다. realtime은 블랙리스트를 신경 쓰지 않는다
- 감수하는 것: 로그아웃·정지·비밀번호 변경 뒤에도 최대 30분은 옛 액세스 토큰이 통한다. 즉시 차단이 꼭 필요해지면 새 ADR로 다시 정한다
